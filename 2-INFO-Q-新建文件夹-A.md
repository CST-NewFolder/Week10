4. Should companies be permitted to collect and use personal data without explicit consent if doing so could produce significant benefits for society, such as improving medical research or developing safer AI systems? How should society balance individual privacy rights against collective benefits, and who should have the authority to make that decision?

A: Companies SHOULD NOT collect and use any personal data without consent since these data belongs to individual
privacy, no matter these data could produce benefits or not, for society or not. To balance privacy rights and data
usage for benefit production, companies should reserve collection function, yet it should be run if and only if user
select to share related data through applications' requests. User should always be the only person, the only authority
to make the decision.
